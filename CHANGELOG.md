# Changelog

## Unreleased

### Added — a portrait for every critter
- All 59 critters have a painted portrait and token, replacing the placeholder
  icon. Each is based on the creature's illustration in the book where there is one,
  shown in its own habitat.
- Tokens keep their rotation locked, like the system's own creature portraits.

## 0.1.0 — Bestiary

First release. The complete *Paranormal Animals of Europe* (FASA 7112)
bestiary as SR2E critter actors — **59 creatures** (A through Appendix I faerie
critters), every stat block verified against the page renders, built for the `sr2e`
system.

The setting/flavour text is not imported — game statistics only.
